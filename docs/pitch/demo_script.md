# Demo Script

> Write v0 right after choosing the idea (T+1:30); it drives what we build. Rehearse the final version at least 3 times with a timer.

## Setup (before going on stage)
- [ ] Demo laptop on hotspot, charged, Do-Not-Disturb ON, unrelated tabs closed
- [ ] Browser zoom 125–150%; the app pre-loaded on the starting screen; logged in
- [ ] Demo data seeded / demo mode ON; the input files/text ready to paste
- [ ] Backup video downloaded locally and open in a paused player
- [ ] One person talks while another drives the mouse (decided in advance)
